# Portfolio — NOGBOU Arnold

Portfolio personnel statique réalisé en HTML, CSS et JavaScript.

## Lancer le site en local
Ouvre `index.html` dans ton navigateur. Pour un meilleur confort de développement, utilise l'extension Live Server de VS Code si tu l'as installée.

## Personnalisation obligatoire avant publication
1. Remplace `assets/images/portrait-placeholder.svg` dans `index.html` par ta photo, idéalement `assets/images/portrait.jpg`.
2. Remplace `tonadresse@email.com` par ton adresse e-mail réelle.
3. Ajoute ton numéro, ton établissement, tes vrais liens GitHub et LinkedIn.
4. Ajoute ton CV PDF dans `assets/documents/` sous le nom `CV-Arnold-Nogbou.pdf`.
5. Vérifie le statut de chaque projet et ajoute uniquement des liens/captures réels.

## Déployer sur Vercel
1. Crée un compte sur https://vercel.com avec GitHub.
2. Crée un dépôt GitHub et envoie-y le contenu de ce dossier.
3. Dans Vercel, choisis **Add New → Project**, puis importe le dépôt.
4. Pour ce site HTML/CSS/JS : Framework Preset **Other**, Build Command vide, Output Directory `.`.
5. Clique sur **Deploy**. Vercel fournira une URL publique.
6. À chaque mise à jour envoyée sur la branche principale de GitHub, Vercel pourra redéployer le site automatiquement.

Aucune commande de build ni framework n'est nécessaire pour cette première version.
